Textgestaltung mit CSS

In diesem Abschnitt werden wir uns mit der Gestaltung von Texten in HTML beschäftigen. Wir werden verschiedene CSS-Eigenschaften kennenlernen, die es uns ermöglichen, das Aussehen von Texten zu verändern und anzupassen.

Schriftart und Schriftgröße

Mit der Eigenschaft font-family können wir die Schriftart eines Textes festlegen. Zum Beispiel:

hier 
  • p {
  font-family: Arial, sans-serif;
}
